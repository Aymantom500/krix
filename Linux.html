📌 قبل أن تبدأ

  • جهّز بيئة لينكس: إما جهاز وهمي باستخدام VirtualBox مع Ubuntu، أو WSL2 على ويندوز، أو Docker container، أو مباشرة على حاسوبك إن كنت تستخدم لينكس.
  • افتح الطرفية (Terminal) وكن مستعداً لكتابة كل أمر بيدك. لا تنسخ وتلصق إلا بعد أن تفهم.
  • كل أمر موجود هنا اقرأ شرحه ثم نفّذه، ثم غيّر فيه لتختبر فهمك.

🔰 المستوى الأول: الأساسيات المطلقة (File System & Navigation)

الدرس 1: ما هي الشيل (Shell) وكيف تعمل الطرفية

  • عند فتح الطرفية، أنت تتحدث مع برنامج اسمه shell (غالباً bash أو zsh).
  • يقرأ هذا البرنامج أوامرك وينفذها، ويظهر لك النتائج.
  • المحث (prompt) يخبرك باسم المستخدم واسم الجهاز والمسار الحالي وينتظر إدخالك:
username@hostname:~$

علامة ~ ترمز إلى مجلد المنزل (Home) الخاص بك.

الأوامر الأولى

echo "Hello, Terminal"

echo يطبع ما تكتبه. جرب echo $HOME أو echo $USER لترى متغيرات البيئة.

date

يعرض التاريخ والوقت.

whoami

يعرض اسم المستخدم الحالي.

clear

يمسح الشاشة (أو استخدم Ctrl+L).

🏋️ التمرين

  1. افتح الطرفية واطبع جملة ترحيبية.
  2. اعرض التاريخ، ثم امسح الشاشة.
  3. اطبع اسم المستخدم ومجلد المنزل باستخدام المتغيرات.

الدرس 2: التعامل مع المجلدات والمسارات

نظام الملفات في لينكس هو شجرة تبدأ من الجذر /.

pwd (print working directory): يطبع المسار الحالي.

pwd

الناتج غالباً /home/username.

التنقل بين المجلدات

  • ls: عرض محتويات المجلد الحالي.
ls
                ls -l   # عرض تفصيلي (صلاحيات، حجم، تاريخ)
                ls -a   # عرض الملفات المخفية (التي تبدأ بنقطة)
                ls -lh  # حجم مقروء للإنسان (مثل 1K, 234M)
            ls -la  # دمج الخيارين
  • cd: تغيير المجلد (change directory).
cd /            # انتقل إلى الجذر
                cd ~            # انتقل إلى المنزل
                cd ..           # انتقل للمجلد الأب
                cd ../..        # مستويين للأعلى
                cd -            # العودة للمجلد السابق
            cd              # بدون وسيط يعيدك للمنزل
  • المسارات النسبية والمطلقة:
    • مطلق: يبدأ من الجذر /home/user/Documents
    • نسبي: بالنسبة للمجلد الحالي Documents/Projects

إنشاء وحذف المجلدات

mkdir new_folder        # إنشاء مجلد
                mkdir -p a/b/c          # إنشاء سلسلة مجلدات دفعة واحدة (أيضاً ينشئ الآباء إن لم توجد)
                rmdir empty_folder      # حذف مجلد فارغ
                rm -r folder            # حذف مجلد بمحتوياته (انتبه، لا سلة مهملات!)
            rm -ri folder           # حذف مع طلب تأكيد لكل ملف

🏋️ التمرين

  1. انتقل إلى المجلد الجذر، شاهد محتوياته، ثم عد إلى المنزل.
  2. أنشئ مجلد باسم test داخل المنزل، وبداخله مجلدين src و bin باستخدام أمر واحد.
  3. احذف المجلد test مع تأكيد الحذف لكل عنصر.
  4. استخدم ls -la في المنزل وحدد الملفات المخفية.

الدرس 3: الملفات – الإنشاء والعرض والنسخ والنقل

في لينكس "كل شيء ملف" حتى الأجهزة.

إنشاء ملفات فارغة أو بمحتوى

touch file.txt                # إنشاء ملف فارغ أو تحديث وقت التعديل إن كان موجوداً
                echo "Hello" > greeting.txt   # إعادة توجيه مخرجات echo إلى ملف (ينشئه أو يمسح محتواه القديم)
            echo "Second line" >> greeting.txt  # إلحاق بالنهاية (append)

عرض محتوى الملفات

cat greeting.txt     # طباعة المحتوى كاملاً
                less greeting.txt    # عرض تفاعلي (استخدم المسافة للصفحة التالية، q للخروج)
                head -n 5 file.txt   # أول 5 أسطر
                tail -n 5 file.txt   # آخر 5 أسطر
            tail -f log.txt      # متابعة الملف في الزمن الحقيقي (مهم لمراقبة السجلات)

نسخ ونقل وإعادة تسمية

cp source.txt dest.txt       # نسخ
                cp -r folder1 folder2        # نسخ مجلد بمحتوياته
                mv oldname.txt newname.txt   # إعادة تسمية أو نقل
            mv file.txt /path/to/dest/   # نقل الملف

حذف الملفات

rm file.txt          # حذف ملف
            rm -i file.txt       # تأكيد قبل الحذف

🏋️ التمرين

  1. أنشئ ملفاً باسم notes.txt واكتب فيه 10 أسطر بأي نص (باستخدام echo والإلحاق عدة مرات).
  2. اعرض أول 3 أسطر وآخر 3 أسطر.
  3. انسخ الملف إلى notes_backup.txt، ثم احذف الملف الأصلي.
  4. افتح الملف المنسوخ بـ less وتجول داخله.

الدرس 4: الصلاحيات والمستخدمين

كل ملف له مالك ومجموعة وثلاث مجموعات صلاحيات: للمالك (user)، للمجموعة (group)، للآخرين (others).

الصلاحيات: قراءة (r=4)، كتابة (w=2)، تنفيذ (x=1).

ls -l
            # -rw-r--r-- 1 user group 1234 Jan 1 12:34 file.txt
  • أول حرف - لملف عادي، d لمجلد، l لرابط رمزي.
  • الرموز التالية: rw- للمالك، r-- للمجموعة، r-- للآخرين.

تغيير الصلاحيات

chmod 755 script.sh     # rwxr-xr-x
                chmod +x script.sh      # إضافة صلاحية التنفيذ للجميع
                chmod u+x script.sh     # إضافة تنفيذ للمالك فقط
            chmod go-w file.txt     # إزالة الكتابة للمجموعة والآخرين

تغيير المالك والمجموعة

chown user:group file.txt
            chown -R user:group folder/   # تغيير تكراري

عادة تحتاج sudo لتغيير المالك.

sudo وتنفيذ الأوامر كمدير النظام

sudo command ينفذ الأمر بصلاحيات الجذر (root). يستخدم بحذر. تعديل ملفات النظام يحتاج sudo.

🏋️ التمرين

  1. أنشئ سكريبت بسيط hello.sh يحتوي على #!/bin/bash وسطر echo "Hello".
  2. شاهد صلاحياته، ثم اجعله قابلاً للتنفيذ ونفّذه (./hello.sh).
  3. جرب تغيير صلاحياته لتكون للقراءة فقط ثم حاول تعديله بـ echo "new line" >> hello.sh (سيُرفض).
  4. أنشئ مجلداً، غيّر صلاحياته بحيث لا يمكن دخوله (مثلاً chmod 000 folder)، ثم حاول cd إليه لترى الخطأ.

📝 المستوى الثاني: معالجة النصوص وإعادة التوجيه (Text Processing & Redirection)

الدرس 5: القنوات (Pipes) وإعادة التوجيه

كل أمر له مدخل قياسي (stdin)، مخرج قياسي (stdout)، ومخرج أخطاء (stderr). يمكن توجيهها:

command > file      # stdout إلى ملف (مسح المحتوى)
                command >> file     # stdout إلى ملف (إلحاق)
                command 2> file     # stderr إلى ملف
                command &> file     # كلاهما إلى ملف
            command < file      # stdin من ملف

الأنابيب (pipe) | تأخذ مخرج أمر وتجعله مدخلاً لأمر آخر:

ls -l | grep "txt"        # إظهار الملفات التي تحتوي txt
            cat /var/log/syslog | less

أوامر التصفية الأساسية

grep "pattern" file        # البحث عن نمط في ملف
                grep -i "pattern" file     # تجاهل حالة الأحرف
                grep -r "TODO" ./src       # بحث تكراري في مجلد
                grep -v "pattern" file     # عكس البحث (الأسطر التي لا تحتوي النمط)
                grep -c "error" log.txt    # عد الأسطر المتطابقة
                sort file.txt              # ترتيب أبجدي
                sort -n numbers.txt        # ترتيب رقمي
                sort -r                    # عكسي
            sort -u                    # إزالة التكرار
wc file.txt        # عدد الأسطر والكلمات والحروف
            wc -l file.txt     # عدد الأسطر فقط
uniq file.txt           # إزالة الأسطر المكررة المتجاورة (غالباً بعد sort)
            uniq -c                 # عد تكرار كل سطر
cut -d':' -f1 /etc/passwd   # استخراج الحقل الأول باستخدام ':' كفاصل
            cut -c1-5 file.txt          # استخراج الأحرف من 1 إلى 5
tr 'a-z' 'A-Z' < file.txt   # تحويل لحروف كبيرة
            tr -d '\r' < winfile.txt    # حذف رمز العودة (\r) لتحويل ملفات ويندوز

🏋️ التمرين

  1. أنشئ ملف names.txt يحتوي 20 اسماً مكرراً وغير مرتب. ثم نفذ:
    • sort names.txt | uniq لاستخراج قائمة فريدة.
    • sort names.txt | uniq -c | sort -nr لترتيب الأسماء حسب التكرار.
    • grep -c "^A" names.txt لعد الأسماء التي تبدأ بحرف A.
  2. خذ مخرجات ls -la ومررها لـ grep لإظهار الملفات التي امتدادها .txt فقط.
  3. استخدم cut مع /etc/passwd لعرض أسماء المستخدمين وقذائفهم.
  4. وجّه stderr لأمر غير موجود إلى ملف error.log.

الدرس 6: أدوات النص المتقدمة – awk و sed (لمحة أولى)

سنتعمق لاحقاً، لكن الأساسيات الآن.

sed (محرر التيار)

sed 's/old/new/' file.txt          # استبدال أول ظهور في كل سطر
                sed 's/old/new/g' file.txt         # استبدال كل الظهورات
                sed '/pattern/d' file.txt          # حذف الأسطر التي تحوي النمط
            sed -i 's/foo/bar/g' file.txt      # تعديل الملف في مكانه (احذر)

awk (لغة معالجة نصوص عمودية)

awk '{print $1}' file.txt            # طباعة العمود الأول (افتراضي الفاصل مسافة)
                awk -F':' '{print $1, $3}' /etc/passwd  # فاصل مخصص، ثم عمودين
            awk '$3 > 1000 {print $1}' /etc/passwd  # شرط: المستخدمين ذوي UID > 1000

🏋️ التمرين

  1. أنشئ ملف CSV بسيط (استخدم فاصلة كفاصل): name,age,grade واملأه ببعض البيانات.
  2. استخدم awk -F',' '{print $1, $3}' file.csv لاستخراج الاسم والدرجة.
  3. استخدم sed لتغيير كل فاصلة إلى فاصلة منقوطة.
  4. استخدم awk لحساب مجموع عمود الأعمار.

💻 المستوى الثالث: أساسيات كتابة سكريبتات Bash

الدرس 7: المتغيرات والمصفوفات

#!/bin/bash
                name="Ahmed"
                age=25
            echo "Name: $name, Age: $age"
  • لا توجد مسافات حول = في تعريف المتغير.
  • لاستخدام المتغير: $var أو ${var} (لحماية من الالتباس).
  • متغيرات خاصة: $0 اسم السكريبت، $1, $2, ... وسائط السكريبت، $# عدد الوسائط، $@ كل الوسائط كقائمة، $? قيمة الخروج للأمر الأخير (0 يعني نجاح).
array=(one two three)
                echo ${array[1]}   # ثاني عنصر
            echo ${array[@]}   # كل العناصر

الأمر read

echo "Enter your name:"
                read username
            echo "Hello, $username"

العمليات الحسابية

result=$((5 + 3))
            echo $result

🏋️ التمرين

  1. اكتب سكريبت greet.sh يأخذ اسم المستخدم كوسيط أول ويطبع "Hello, [name]". إن لم يعطَ وسيطاً، يطلب إدخاله بـ read.
  2. أنشئ مصفوفة بخمس كلمات واطبعها واحدة واحدة باستخدام حلقة for.

الدرس 8: العبارات الشرطية والحلقات

if

if [ $age -ge 18 ]; then
                    echo "Adult"
                elif [ $age -ge 13 ]; then
                    echo "Teen"
                else
                    echo "Child"
            fi
  • المقارنات العددية: -eq, -ne, -lt, -le, -gt, -ge.
  • مقارنات النصوص: =, !=, -z (سلسلة فارغة)، -n (غير فارغة).
  • اختبار الملفات: -f file (موجود وملف عادي)، -d dir (موجود ومجلد)، -x file (قابل للتنفيذ)، إلخ.
  • [[ ]] أفضل من [ ] لأنها تدعم أنماط وتعابير نمطية.

case

case $var in
                    start)
                        echo "Starting...";;
                    stop)
                        echo "Stopping...";;
                    *)
                        echo "Unknown";;
            esac

الحلقات

for i in 1 2 3; do
                    echo $i
                done
                for file in *.txt; do
                    echo "Processing $file"
                done
                while [ $count -le 5 ]; do
                    echo $count
                    ((count++))
            done

🏋️ التمرين

  1. اكتب سكريبت يختبر ما إذا كان الملف المعطى كوسيط موجوداً، ويطبع "موجود" أم لا.
  2. اكتب سكريبت يأخذ امتداد ملفات كوسيط (مثلاً txt) ويطبع أسماء كل الملفات بهذا الامتداد في المجلد الحالي، ثم يعدها.
  3. استخدم while لقراءة ملف سطراً سطراً (استخدم while read line).

الدرس 9: الدوال ونطاق المتغيرات

function greet {
                    local name=$1   # local يجعل المتغير محلياً داخل الدالة
                    echo "Hello, $name"
                }
            greet "Ali"

الخروج من دالة بقيمة: return 0 (تصل عبر $?). لكن لاسترجاع نصوص، استخدم echo مع capture: result=$(my_func).

🏋️ التمرين

  1. اكتب سكريبتاً به دالة تحسب مضروب عدد (factorial) باستخدام التكرار أو recursion، ثم استدعها.
  2. أنشئ دالة log تطبع رسالة مع طابع زمني.
  3. استخدم source لتضمين دوال من ملف آخر (مثل utils.sh).

⚙️ المستوى الرابع: إدارة النظام والعمليات (System & Process Management)

الدرس 10: إدارة العمليات

ps aux                 # عرض كل العمليات
                top                    # مراقبة مباشرة (اضغط q للخروج)
            htop                   # بديل محسن إن كان مثبتاً

تشغيل أمر في الخلفية:

command &
  • jobs يعرض المهام الخلفية.
  • fg %1 لإرجاع المهمة رقم 1 للأمام.
  • bg %1 لإكمال مهمة موقوفة في الخلفية.
  • kill PID لإيقاف عملية (PID من ps). kill -9 PID للقتل الإجباري.
  • killall process_name لقتل كل العمليات بهذا الاسم.
  • nohup command & لتشغيل أمر يستمر حتى بعد إغلاق الطرفية.
  • disown لفصل عملية من الجلسة.

مراقبة الموارد

free -h        # الذاكرة
                df -h          # مساحة الأقراص
            du -sh folder  # حجم مجلد

🏋️ التمرين

  1. افتح محرر gedit (أو أي برنامج) من الطرفية ثم أوقفه بـ Ctrl+Z، اكتب jobs ثم fg.
  2. شغّل أمر sleep 100 &، ثم اقتله باستخدام PID.
  3. اكتب أمراً يراقب ملف log ويتابع إضافاته: tail -f /var/log/syslog ثم قاطعه بـ Ctrl+C.
  4. استخدم du -sh * | sort -h في مجلد المنزل لترتيب المجلدات حسب الحجم.

الدرس 11: المهام المجدولة (Cron)

crontab -e    # تعديل جدول المهام للمستخدم
            crontab -l    # عرض الجدول

الصيغة: دقيقة ساعة يوم_الشهر شهر يوم_الأسبوع الأمر

مثال: كل يوم عند 2:30 صباحاً: 30 2 * * * /home/user/backup.sh

تدوينات خاصة: @reboot, @daily, @hourly.

🏋️ التمرين

  1. أنشئ سكريبت يكتب "Hello from cron" مع التاريخ إلى ملف في /tmp/cron_test.log.

الدرس 25: محرر Vim (أساسيات للمحترف)

لأنك غالباً ستعدل ملفات على خوادم بعيدة، وأحياناً هو المحرر الوحيد.

الأوضاع

  • الوضع العادي (Normal): للتجول والأوامر.
  • وضع الإدراج (Insert): للكتابة (اضغط i).
  • وضع الأوامر (Command): : للتنفيذ.

أساسيات

i       -> إدراج قبل المؤشر
                a       -> إدراج بعد المؤشر
                Esc     -> العودة للوضع العادي
                :w      -> حفظ
                :q      -> خروج
                :wq     -> حفظ وخروج
                :q!     -> خروج بدون حفظ
                dd      -> حذف سطر
                yy      -> نسخ سطر
                p       -> لصق
                /pattern -> بحث (n التالي، N السابق)
                u       -> تراجع
            Ctrl+r  -> إعادة

🏋️ التمرين

  1. افتح vim وأنشئ ملفاً جديداً، اكتب نصاً، احفظ واخرج.
  2. افتح ملفاً موجوداً، ابحث عن كلمة واستبدلها (:%s/old/new/g).
  3. قسم النافذة :split أو :vsplit وتنقل بينها.
  4. قم بتثبيت vim-plug وأضف بعض الإضافات (plugin) مثل NERDTree.

الدرس 28: معالجة البيانات الضخمة باستخدام أدوات CLI

في كثير من الأحيان، تحتاج لاستكشاف أو تنظيف ملفات بيانات ضخمة (عدة جيجابايت) قبل إدخالها في بايثون. الأوامر CLI أسرع بكثير.

  • استخدام head/tail لمعاينة.
  • wc -l لعد الأسطر.
  • split لتقسيم ملفات ضخمة:
split -l 100000 huge.csv part_    # يقسم كل 100 ألف سطر
  • awk لمعالجة سطرية: جمع، تصفية.
  • sort مع خيار -S لتحديد حجم الذاكرة، و -T لمجلد مؤقت لملفات ضخمة.
  • grep -c لعد الأنماط.
  • استخدام pv لمراقبة تقدم الأنابيب:
pv large_file.csv | gzip > large_file.csv.gz
  • jq لمعالجة JSONL (سطر JSON في كل سطر).

🏋️ تمرين عملي

  1. أنشئ ملف CSV كبير (بضعة ملايين سطور) باستخدام برنامج صغير أو seq مع awk. ثم استخدم split لتقسيمه، و cat لدمج الأجزاء.
  2. استخدم awk لحساب إحصاءات سريعة على عمود.
  3. استخدم grep مع -c لعد الأنماط ثم sort -nr لترتيب النتائج.

الدرس 29: أتمتة سير العمل (Workflow Automation) باستخدام Bash و Make

بناء Makefile لمشاريع بايثون/تعلم آلة:

data/raw.csv: src/download.py
                    python src/download.py
                data/processed.csv: data/raw.csv src/preprocess.py
                    python src/preprocess.py
                train: data/processed.csv src/train.py
                    python src/train.py
                clean:
                rm -f data/*.csv models/*.pkl

استخدام make يضمن إعادة تشغيل الخطوات عند تغير الاعتماديات.

كتابة سكريبتات Bash لتشغيل تجارب متعددة بمعاملات مختلفة:

for lr in 0.001 0.01 0.1; do
                    for bs in 32 64; do
                        echo "Training with lr=$lr batch_size=$bs"
                        python train.py --lr $lr --batch-size $bs
                    done
            done

حفظ المخرجات لكل تجربة:

python train.py --lr $lr > "logs/lr_${lr}_bs_${bs}.log" 2>&1

🏋️ التمرين

  1. اكتب Makefile لمشروع تعلم آلة خيالي، وتعمد تغيير أحد الملفات لتشاهد كيف يعيد make بناء المعتمديات.
  2. اكتب سكريبت Bash يمر على قائمة ملفات إعدادات (config.yaml) ويشغل تدريباً لكل منها، وينشئ تقريراً بالأداء باستخدام grep على ملفات السجلات.

  1. أنشئ متغير بيئة MY_VAR وجرب الوصول إليه من Bash ومن Python.
  2. اكتب سكريبت يستخدم متغير بيئة لكلمة مرور قاعدة البيانات ويخفيها عن ps (لا تظهر في ps aux).

الدرس 31: ضغط وأرشفة الملفات

tar -czvf archive.tar.gz folder/   # إنشاء أرشيف مضغوط بـ gzip
                tar -xzvf archive.tar.gz           # فك الضغط
                tar -cjvf archive.tar.bz2 folder/  # bzip2 (ضغط أقوى)
            tar -xJvf archive.tar.xz           # xz

التعامل مع zip:

zip -r archive.zip folder/
            unzip archive.zip

استخدام gzip و gunzip مباشرة على ملفات.

🏋️ التمرين

  1. أنشئ أرشيفاً لمشروعك يحتوي على ملفات ومجلدات، ثم انقله لمسار آخر وفك ضغطه.
  2. قارن بين أحجام الأرشيفات باستخدام gzip, bzip2, xz.

الدرس 32: التعامل مع النصوص الثنائية والبيانات (Hexdump, xxd)

hexdump -C file.bin | head
            xxd file.bin

مفيد لفحص الملفات الثنائية، النماذج، أو تصحيح تنسيقات.

🏋️ التمرين

  1. أنشئ ملفاً نصياً عادياً وملفاً ثنائياً بسيطاً، وقارن مخرجات xxd.

الدرس 33: البحث المتقدم عن الملفات (find, locate)

find /path -name "*.py"                # بالاسم
                find /path -type f -mtime -7           # عدلت خلال 7 أيام
                find /path -size +10M                  # أكبر من 10 ميجا
            find . -name "*.log" -exec rm {} \;    # تنفيذ أمر على النتائج (احذر)

locate filename أسرع لكن يعتمد على قاعدة بيانات تحدث دورياً (sudo updatedb).

🏋️ التمرين

  1. ابحث عن كل ملفات .jpg التي تزيد عن 1 ميجا في مجلد الصور.
  2. استخدم find لنسخ جميع ملفات .txt من شجرة مجلدات إلى مجلد وجهة واحد.

الدرس 34: أدوات متقدمة لمراقبة الأداء وتحليل النظام (strace, lsof, iostat, vmstat)

  • lsof (list open files): كل شيء ملف، لذا يظهر الملفات المفتوحة والمآخذ.
lsof -p PID
            lsof -i :80            # ما يستخدم المنفذ 80
  • strace -p PID لتتبع استدعاءات النظام لعملية عاملة (مفيد جداً للتصحيح).
  • vmstat 1 لإحصائيات الذاكرة والـ CPU.
  • iostat -x 1 لإحصائيات القرص (يحتاج sysstat).

🏋️ التمرين

  1. ابدأ عملية Python بسيطة، ابحث عن PID الخاص بها، وشاهد الملفات المفتوحة باستخدام lsof.
  2. استخدم strace على أمر ls وشاهد الاستدعاءات.

الدرس 35: التعامل مع الحاويات من سطر الأوامر – Docker Compose (إضافي)

ملف docker-compose.yml:

version: '3'
                services:
                  web:
                    build: .
                    ports:
                      - "5000:5000"
                    volumes:
                      - .:/app
                  redis:
                image: "redis:alpine"

أوامر:

docker-compose up -d
                docker-compose logs -f
            docker-compose down

🏋️ التمرين

  1. أعد مشروع ويب بسيط مع Redis و Flask، استخدم docker-compose.

الدرس 36: كتابة سكريبتات إنتاجية قوية (Advanced Shell Scripting)

التعامل مع الإشارات (trap):

trap 'echo "Interrupted"; exit 1' INT

معالجة الخيارات باستخدام getopts:

while getopts "f:o:" opt; do
                  case $opt in
                    f) input_file=$OPTARG ;;
                    o) output_file=$OPTARG ;;
                  esac
            done

الأوامر الشرطية && و ||:

mkdir new_dir && cd new_dir || echo "Failed"

التحقق من نجاح الأوامر واستخدام set -e (الخروج عند الخطأ)، set -u (خطأ عند متغير غير معرف)، set -o pipefail (خطأ إذا فشل أي جزء في الأنبوب).

🏋️ التمرين

  1. اكتب سكريبت يأخذ مسار إدخال ومجلد إخراج كخيارات، يعالج جميع ملفات CSV بالإدخال وينتج ملخصاً.
  2. اكتب سكريبتاً به trap لتنظيف ملفات مؤقتة عند الخروج.

الدرس 37: إدارة العمليات المتوازية (GNU parallel)

أداة parallel لتشغيل أوامر متوازية.

seq 10 | parallel echo "Number {}"
                find . -name "*.jpg" | parallel convert {} {.}.png   # تحويل الصور دفعة
            parallel -j 4 gzip ::: *.log                          # ضغط بأربع مهام متوازية

مفيد في معالجة بيانات كبيرة بسرعة.

🏋️ التمرين

  1. قم بتنزيل قائمة URLs، واستخدم parallel لتنزيلها بالتوازي باستخدام wget.
  2. استخدم parallel لتطبيق jq على العديد من ملفات JSON.

الدرس 38: استخدام متقدم لـ awk

لنفترض ملف server.log به أعمدة: IP, time, status, size.

awk '{sum[$1] += $4} END {for (ip in sum) print ip, sum[ip]}' log.txt

تجميع وإحصائيات مباشرة، بديل لـ SQL البسيطة.

🏋️ التمرين

  1. على ملف سجلات وهمي، استخدم awk لحساب عدد الطلبات لكل عنوان IP وحجم البيانات المنقولة.

الدرس 39: إعداد بيئة تطوير متكاملة في الطرفية (Vim/Tmux + أدوات)

  • استخدم fzf للبحث التفاعلي عن الملفات والتاريخ.
  • ripgrep (rg) للبحث النصي فائق السرعة.
  • bat بديل cat مع تلوين للصيغ.
  • delta لعرض diffs جميلة.
  • كلها يمكن دمجها لصنع IDE طرفي.

🏋️ التمرين

  1. ثبت fzf واستخدم CTRL-T للبحث عن ملفات.
  2. استخدم rg للبحث عن كل استدعاءات دالة معينة في مشروع كبير.

الدرس 40: مشاريع نهائية تطبيقية

لتجمع كل المهارات، أنجز المشاريع التالية من سطر الأوامر فقط (بأقل استخدام لـ GUI):

المشروع 1: خط أنابيب بيانات (Data Pipeline) بالكامل في Bash

  • قم بتنزيل ملف CSV من الإنترنت باستخدام curl أو wget.
  • نظفه باستخدام awk / sed (إزالة أعمدة، استبدال قيم).
  • قسمه إلى ملفات صغيرة حسب قيمة حقل معين (باستخدام awk و sort).
  • احسب إحصائيات وصفية باستخدام csvstat أو awk.
  • أنشئ أرشيفاً بالمخرجات وأرسله إلى خدمة تخزين (مثلاً تحميله إلى خادم SFTP بواسطة scp).
  • جدول العملية بـ cron.

المشروع 2: إدارة تجارب تعلم آلي

  • اكتب Makefile لتحميل البيانات، معالجتها، تدريب نموذج، وتقييمه.
  • اكتب سكريبت run_experiments.sh يأخذ ملف hyperparameters (CSV) ويشغل التدريب لكل صف، مع تسجيل المخرجات في مجلدات مؤرخة.
  • استخدم nvidia-smi لمراقبة وإيقاف التدريب إذا تجاوزت حرارة GPU حداً معيناً.
  • أرسل إشعاراً عند الانتهاء (باستخدام curl لـ Telegram Bot أو mail).
  • شغل كل شيء داخل حاوية Docker باستخدام docker-compose.

المشروع 3: أتمتة بيئة تطوير محمولة

  • اكتب سكريبت setup.sh يثبت كل أدواتك المفضلة (git, vim, tmux, fzf, oh-my-zsh...) ويستنسخ dotfiles من مستودع Git.
  • استخدم stow لإدارة dotfiles.
  • يجب أن يعمل السكريبت على توزيعة جديدة ويجعل البيئة جاهزة للعمل.
